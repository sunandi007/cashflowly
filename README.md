# 💰 Cashflowly

A personal finance tracking app built with **Expo + React Native + Supabase**.

## 🚀 Features
- Email authentication (Supabase)
- Add/Edit/Delete transactions
- Category-based filtering
- Profile management
- Service Worker-ready PWA
- Multi-wallet support (coming soon)

## 🧠 Tech Stack
- **Expo SDK 51**
- **React Query**
- **Supabase** (Auth + Storage + Database)
- **TypeScript**
- **NativeWind** for styling
- **React Navigation v6**

## 🧰 Setup
```bash
git clone https://github.com/sunandi007/cashflowly.git
cd cashflowly
npm install
npx expo start
